A complete Data Engineering + Business Intelligence + Machine Learning Solution that transforms raw customer data into strategic business decisions through:

ETL + Data Warehouse + Dashboard + Churn Prediction

This project focuses on building a complete ETL (Extract, Transform, Load) process using SQL Server and developing an interactive Power BI Dashboard to analyze customer behavior, identify churn patterns, and predict future customer churn using the Random Forest Machine Learning Algorithm.

The primary goal is to transform raw customer data from CSV files into meaningful business insights that help organizations improve customer retention strategies and implement targeted marketing campaigns.
